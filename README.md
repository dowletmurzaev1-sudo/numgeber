# НомГен

**Крути. Собирай. Богатей. Найди номер мечты!**

Браузерный симулятор коллекционера российских автомобильных номеров.

## Как играть
1. Начни с баланса **5 000 ₽**.
2. Нажми «Крутить генератор» — одна попытка стоит **500 ₽**.
3. Получай случайные номера пяти уровней редкости.
4. Оставляй лучшие находки в коллекции, продавай отдельные номера или дубликаты.
5. Следи за балансом, стоимостью коллекции и историей сделок.

## Редкости
| Уровень | Вероятность |
|---|---:|
| Обычный | 69,5% |
| Редкий | 22% |
| Эпический | 7% |
| Мифический | 1,5% |
| Легендарный | 0,5% |

Стоимость зависит от редкости и красоты комбинации цифр и букв. Все номера и цены — игровые условности.

## Запуск
Откройте `index.html` в современном браузере. Сборка и сервер не требуются.

Прогресс автоматически сохраняется в LocalStorage текущего браузера.

## Файлы
- `index.html` — разметка интерфейса.
- `style.css` — оформление и адаптивная вёрстка.
- `app.js` — генератор, экономика, коллекция и сохранение.

## Подключение Supabase для глобальных шансов
1. Создай проект Supabase и скопируй Project URL и anon/publishable key из Project Settings → API.
2. Впиши их в `supabase-config.js`.
3. Выполни `supabase/schema.sql` в SQL Editor.
4. Создай аккаунт администратора в Authentication → Users.
5. Добавь UUID этого аккаунта в `public.nomgen_admins` запросом, указанным в конце SQL-файла.
6. Включи Realtime для `nomgen_settings` в Database → Publications → supabase_realtime.
7. Опубликуй сайт заново. Вход в админ-панель — email и пароль Supabase.
Используй только anon/publishable key в браузере. Никогда не размещай service_role key на клиенте.
